Four rules that apply everywhere

  • No Site Settings globals. Every colour and font is typed in per widget from these tables. Do not create global colours or global fonts.
  • Name every container in the Structure panel the moment you create it, using the name from the tree diagram. Right-click the container → Rename.
  • Build one, then duplicate. Where a card repeats, finish the first completely, then right-click → Duplicate and change only the content.
  • Leave Advanced › Overflow on Default unless a table says Hidden. Three sections depend on CSS sticky, and one parent set to Hidden silently kills it.

About the fonts

Inter is a Google Font. The first time you pick it in any Typography control, Elementor loads it for the whole page. There is nothing to install.

The original design uses Satoshi for the four big stat numbers. Satoshi is not a Google Font and is almost certainly not on this site. Use Inter at weight 500 for those numbers. Do not go hunting for Satoshi; the difference is invisible at a glance.

1d · The global CSS block

Still in Page Settings, open the Advanced tab → Custom CSS and paste this. Two lines, both necessary.

html{scroll-behavior:smooth}
#home,#panels,#about,#services,#facilities,#how,#reviews,#faq,#contact{scroll-margin-top:110px}
LineWhat it does
scroll-behaviorMakes the menu links glide instead of snapping.
scroll-margin-topWithout this the sticky header covers the heading you just jumped to. The header is about 92px tall, so every anchor stops 110px early. If you ever change the header height, change this number to match.
Done when: an empty canvas on warm off-white, a "Lumiere Landing" menu saved under Appearance › Menus, and two lines in the page's Custom CSS.

Read this first. The stacking is plain CSS position: sticky. Do not use Motion Effects › Sticky here — that is a different, JavaScript-driven feature and it will not stack. Sticky also stops working if any ancestor has Overflow set to Hidden, so services and svc-stack must both stay on Default.

How the stacking effect actually works

This is the one effect on the page that is not a normal layout, so it is worth understanding before you build it. It is not an animation, there is no JavaScript, and nothing fades or moves on a timer. It is one CSS property doing all of the work.

Every one of the eight cards gets position: sticky with the same top: 100px. Sticky means: behave like a normal element until you would scroll past that point, then stop and stay there. Because all eight share the same stopping point and they sit one after another in the page, each card scrolls up, parks 100px below the top of the screen, and the next card slides up over it. The pinned card never moves again, so by the last card you have a stack of eight, each covering the one before.

The two shadows

The card carries two box shadows, and they do different jobs. Elementor's Box Shadow control only takes one set of values, so the second is added in the Custom CSS box below.

ShadowValuesWhat it does
Downward (panel control)H 0   V 10   Blur 30   Spread −18  rgba(31,40,51,.25)The normal card lift, same as every other card on the page.
Upward (CSS)H 0   V −6   Blur 24   Spread −20  rgba(31,40,51,.3)This is what sells the stack. It darkens the top edge of the arriving card so it reads as sitting on top of the pinned one, not merely scrolling past it. Skip this and the effect looks flat and slightly broken.

The Custom CSS, and where it goes

Select svc-card → Advanced › Custom CSS and paste all of this. The word selector is Elementor's own shorthand for "this element" — leave it exactly as written, do not replace it with a class name.

selector{
  position:sticky;
  top:100px;
  box-shadow:0 -6px 24px -20px rgba(31,40,51,.3),
             0 10px 30px -18px rgba(31,40,51,.25);
}

/* phones: only stack when the screen is tall enough to show a whole card */
@media(max-width:860px) and (min-height:700px){
  selector{position:sticky; top:80px}
}
@media(max-width:860px) and (max-height:699px){
  selector{position:relative; top:auto}
}

Do this on card 1 BEFORE you duplicate. Right-click → Duplicate copies a container's Custom CSS along with everything else, so all eight cards inherit the rule for free. If you build all eight first, you will be pasting the same block eight times.

If you paste the CSS above, you can leave the panel's Style › Box Shadow control switched off entirely — the second line of the CSS already contains both shadows. Use one or the other, not both, or you will end up with three shadows.

Four things that will stop it working

#RequirementWhy
1No ancestor may have Overflow: Hidden. Check svc-card's parents: svc-stack, services, and the page body.A scroll container anywhere above a sticky element silently cancels it. There is no error — the card just behaves normally. This is the single most common cause.
2svc-stack Gap must be 0, and the spacing comes from each card's Margin Bottom 28 instead.A flex gap is added between the flex items, so as the cards pin it keeps forcing them apart and they never overlap.
3top must be larger than the header. The header is about 92px tall, so 100px leaves 8px of breathing room.Set it lower than 92 and the cards pin behind the sticky header and get clipped by it.
4No Entrance Animation on svc-card.Elementor's entrance animations work by transforming the element. A transform on a sticky element fights the pinning, and the cards visibly jump as they park.

How to check it

The Elementor editor canvas does not show this properly. Editing overlays and the canvas's own scrolling interfere, so the cards will look wrong while you are building them. That is expected — do not try to fix it from inside the editor.

  1. Save, then click the eye icon at the bottom of the panel → Preview Changes.
  2. Scroll slowly through the services section. Card 1 should stop near the top and stay there while card 2 rises and covers it.
  3. Keep going. By card 8 you should be looking at a stack, with a faint dark line along the top edge of each arriving card.
  4. Then narrow the browser to phone width and scroll again — the cards should still stack, just tighter.
